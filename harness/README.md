# 하네스 폴더

에이전트 세션은 컨텍스트가 끊기면 이전 일을 기억하지 못한다. 상태는 대화가 아니라
이 폴더의 파일에 남긴다.

- `FEATURES.md` — 작업 단위 목록. 항목마다 검증 기준과 통과 여부(`[ ]`/`[x]`).
  검증 기준은 조율자만 고친다. 워커는 기준을 삭제·완화할 수 없다.
- `PROGRESS.md` — 직전 세션이 무엇을 했고 다음에 뭘 해야 하는지. 새 세션이 가장
  먼저 읽는 파일. 세션을 마칠 때마다 갱신한다.

## 세션 프로토콜

1. 시작 — `git log --oneline -10`과 `PROGRESS.md`를 읽고, 실행 스크립트가 있으면
   돌려 기존 기능이 깨지지 않았는지 확인한다.
2. 선택 — `FEATURES.md`에서 미완 항목 하나만 고른다. 한 세션에 한 단위.
3. 검증 — 그 항목의 검증 기준을 실제로 실행해 통과해야 완료다. 기준을 바꿔서
   통과시키는 것은 금지.
4. 마무리 — 커밋(한국어 메시지)하고 `PROGRESS.md`를 갱신한다.
