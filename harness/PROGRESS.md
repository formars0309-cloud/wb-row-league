## 테스트·실행 방법

- 개발 서버: `npm run dev`
- 빌드: `npm run build` (vinext build, 산출물 `dist/`)
- 테스트: `npm test` — 빌드 후 `tests/rendered-html.test.mjs`를 node --test로 실행.
  dist의 서버 렌더 HTML과 소스 패턴을 함께 단언한다.
- 린트: `npm run lint`
- 요구 환경: Node.js >= 22.13.0
