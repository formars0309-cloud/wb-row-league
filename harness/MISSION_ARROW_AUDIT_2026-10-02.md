# 전체 임무 화살표 검수 — 2026-10-02

- 기준: 사용자 최종 확정 12·6시 용기, 3·9시 치료. 1시 천무·7시 축복, 중앙 위 목명·아래 군왕.
- 실제 구글 시트 스타팅 명단을 읽기 전용으로 수신해 30명×5부대×2진영 300건의 목표와 좌표를 대조했다. 시트 임무는 수정하지 않았다.
- 목표 지정 92건, 고정 목표 없음 208건. 획득 조건의 거점은 제외하고 뒤의 실제 집결 목표로 연결한다.
- 시계와 명칭이 충돌하거나 같은 이름의 두 영목 중 방향이 없으면 임의로 선택하지 않는다. 집결 탑승은 담당 집결장의 임무를 따른다.
- 루시아는 시트의 시계·거점 쌍을 환산한다. 전망대 1/2는 자기 스타팅 쪽 두 개 중 화면 왼쪽/오른쪽이다.
- 종점은 공통 거점 좌표 또는 담당 적 출구 좌표와 일치하며, 화살촉 refX는 꼭짓점 9에 맞춘다.
- 입구막팀 카드 12·14·15·23은 부대·라인 화살표 대신 검은 차단 화살표 1개만 표시한다. 아래 표는 원래 부대 목표 판정이며 차단 카드는 표시를 대체한다.
